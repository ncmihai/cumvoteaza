## Summary

The public site is in better shape than its surroundings. The data layer is now sound (all integrity checks pass), and the September review's defects D3–D8 are already fixed in code.
The weight is elsewhere: **about 26,000 lines of cockpit used for one button**, a demo-data mode threaded through the site's data layer, eleven one-off import commands, a disabled paid-AI feature, and two dead storage backends.
The most important *missing* thing is not code: **the site cannot say whether a vote passed.**

## 4. Privacy and legal

- **Visitor tracking cookie without consent.** `engagement_events` (560 rows) and `content_reactions` (8) use a random visitor-ID cookie (salted hash, no IP) and store raw search queries. In the EU a non-essential cookie needs consent; there is no banner. It powers "popular votes" on the homepage.
  Options: (a) count views without any cookie or identifier (recommended), (b) add a consent banner, (c) remove popularity.
- **Plaintext database password** for another project (`instrumentar`) in the workspace's `.claude/settings.local.json`. Delete those lines and rotate the password.
- **Local work writes to production**: `.env` and `apps/web/.env.local` point at the production database. Recommended: a Neon `dev` branch for local work, with production credentials used only by the runbook and the updater.

### 8.3 Outside the parliament sites

- **Laws:** `legislatie.just.ro` offers a free SOAP web service (`FreeWebService.svc`: token without registration, search by title, number, year; consolidated versions at a chosen date). That is the source for the later "law diff".
- **Cabinets:** presidency.ro decrees and Monitorul Oficial for appointments, dismissals, interim ministers (for example decree 623/2025 for the interim prime minister; decrees 734 and 747/2025 for the Bolojan government); gov.ro lists former prime ministers; Wikipedia and Wikidata are cross-checks only.
- **People:** Wikidata has 3,483 Romanian MPs with birth dates (used for the identity review).
- **Community mirror:** a public project scrapes CDEP into JSON daily (about 3,000 votes, 3,252 bills, 9,758 interpellations, 162 motions, 85,895 committee documents for 2024); useful as a size reference and cross-check, never as a source of truth.

### 8.4 Constraints learned

- **cdep.ro blocks non-Romanian addresses** (the mirror runs its collector from Romania): the updater must run on the BC250 or another Romanian address, never from Vercel.
- CDEP answers some pages with HTTP 500 and drops traffic from shared addresses (docs/cdep-access.md): one request at a time, 2 s apart, stop on errors.
- The Senate site is ASP.NET: calendars and expense months need form postbacks; plain links exist only for the main pages.
